## You are in the tools all day anyway.

Cribble measures active time across ChatGPT, Claude, Cursor, and dozens more, then turns showing up into scores, streaks, seasons, and rank.

Install it. Forget it. Check the board when the group chat gets cocky.

```text
active time  →  daily score  →  streaks  →  seasons  →  bragging rights
```

## The quiet part matters.

Cribble knows *where* you spent time, not *what* you said there.

It records supported domains, active and idle time, visits, and sync timing. It does not read prompts, responses, page content, files, keystrokes, clipboard contents, or screenshots.

[Read the full privacy policy →](https://cribble.dev/privacy)

## Why you can see the code.

A product built around measured activity should be inspectable.
